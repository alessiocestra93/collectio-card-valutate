# Collectio Card Valutate

App interna di Cicciogamer89 TCG per valutare (acquisto) e prezzare (vendita) le carte singole:
Pokémon, One Piece, Dragon Ball Super / Fusion World, Magic, Yu-Gi-Oh!, Lorcana.

- Ricerca nel catalogo Cardmarket con link diretti già filtrati (lingua, condizione, venditori professionali).
- Link a eBay (venduti) e CardTrader.
- Scansione della carta con la fotocamera e lettura gratuita del codice stampato (sul telefono).
- Catalogo aggiornato automaticamente ogni notte da GitHub Actions (`.github/workflows/pages.yml`).

Per aggiornare il catalogo a mano: **Actions → Aggiorna catalogo e pubblica → Run workflow**.

Dati: catalogo prodotti e price guide pubblici di Cardmarket; numeri e set Pokémon da [TCGdex](https://github.com/tcgdex/cards-database).
